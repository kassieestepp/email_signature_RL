# Email Signature — Kassie Estepp / Rocket Lister

Modern, minimal Gmail signature. Accent color `#EE7320`.

## Files used by the signature

- `signature.html` — the signature markup (Gmail-safe: tables + inline styles only)
- `assets/headshot.jpg` — square 320×320 headshot (displayed as a 104px circle), from `headshots/kassieestepp_headshot.JPG`
- `assets/logo-wordmark.png` — black ROCKET LISTER wordmark, rasterized from `LOGO copy 3.pdf`
  (the white-on-black versions don't work on a light email background; the tagline is
  rendered as HTML text instead so it stays readable at small size)

The images are referenced via `raw.githubusercontent.com` URLs, so **this repo must be
public and these files must be pushed to the `main` branch** for them to load in emails.

## Install in Gmail (after pushing this folder to GitHub)

1. Open `signature.html` in a browser (double-click the file).
2. Select everything (`Cmd+A`) and copy (`Cmd+C`).
3. In Gmail: **Settings (gear) → See all settings → General → Signature → Create new**.
4. Paste into the signature box and save changes at the bottom of the page.
5. Send yourself a test email.
